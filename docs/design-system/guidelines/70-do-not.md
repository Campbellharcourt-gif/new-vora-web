# Do not make VORA look like this

| Never | Instead |
|---|---|
| A generic SaaS dashboard — rounded white cards in bento grids, pastel stat tiles, blue buttons, gradient charts | A flat workspace: typographic hierarchy, hairlines, DM Mono data, one accent |
| A template agency site — gradient headline + two buttons + laptop mockup; logo walls; three icon cards; invented stats; testimonial carousels; filler FAQs; the same CTA band on every page | Stations with one idea each; real work in apertures; services as editorial rows; an invitation written per page |
| Glassmorphism — frosted panels, blurred headers | Solid surfaces; the header at 92% with a hairline and no blur |
| Rounded cards everywhere, pills, cards in cards, shadows as separators | `radius-0` for media, `radius-s` for controls; separation by space and hairlines |
| Random gradients, gradient text, mesh blobs | Colour as light in imagery only |
| Glows, neon outlines, orbs, scanlines | Light belongs to the world, never to the interface |
| Excessive animation — everything fading up, letter confetti, scroll-jacking, splash loaders, cursor followers, magnetic buttons, tilt cards | One gesture per shot, reveal once, no custom cursor, a complete reduced-motion version |
| Poor typography — default Inter/Poppins, everything bold, centred paragraphs, tiny grey text | Archivo's two widths at 300–560, measured lines, balanced display lines, DM Mono labels, one italic word |
| Clutter — several CTAs, badges, emoji, icon rows, several accent colours | One idea and one action per shot; negative space |
| AI-generated-looking sections — "Unlock/Elevate/Seamless", sparkle icons, 3D blobs, AI stock people, identical section heights, symmetric everything | Real content or marked slots, asymmetric shots that change, VORA's own rendered world |
| Inconsistent spacing — arbitrary values, misaligned edges | The spacing scale only; one strong alignment per shot |
| Mobile as a compressed desktop — shrunken grids, hover-only information, a tiny dropdown menu | Portrait plates with their own framing, re-broken lines, single-column sequences, the full-screen menu |

**Also excluded:**

- the reference sites' motifs (ALCHE's triangle and violet light, Ascend's ribbed arch, R3's pixel type and particle flora, FIND's cloud descent and cropped footer wordmark);
- Solara's identity (Poppins, cream and gold);
- web3, crypto, gaming and cyberpunk styling.

**The anti-generic gate** — asked before anything ships:

1. Could this belong to any other studio if the logo were removed?
2. Does the opening shot belong to VORA's world?
3. Is the rhythm predictable three times in a row?
4. Is the type doing real work?
5. Is every image real?
6. Does mobile have its own composition?
7. Is anything on screen untrue?
