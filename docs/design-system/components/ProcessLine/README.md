# ProcessLine

VORA's six real process steps on one survey line: Discover, Define, Design, Develop, Refine, Launch.

**The consumer provides:** the steps (the six above, from the Our Story content) and, optionally, one sentence per step as copy.

**Behaviour**

- **Desktop:** a horizontal line with six ticks; each step's text appears as scrolling reaches its tick (scrubbed), and the current tick turns `color-accent`.
- **Mobile:** a vertical line.
- **Reduced motion:** static.
- No invented durations or numbers.
