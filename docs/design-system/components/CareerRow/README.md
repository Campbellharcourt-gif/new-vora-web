# CareerRow

Open roles as hairline rows (title, location type, employment type, location, arrow), with an honest empty state when none are open.

**The consumer provides:** published roles only (`title`, `locationType`, `employmentType`, `locationText`) and the careers email for the empty state. Empty fields are omitted.

**Rules:** the whole row is one link. The four seeded roles (Web Designer, UI/UX Designer, Motion Designer, Developer) are drafts: they appear on the site only once you publish them. They are shown here only to demonstrate the row.
