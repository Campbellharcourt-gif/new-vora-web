# Invitation

The closing shot of each marketing page — its resolved moment — ending on Start a project.

**The consumer provides:** one sentence written for that page (a copy slot per page), the projects email, and optionally a real landscape plate.

**Rules**

- A label `NEXT — START A PROJECT`, the sentence at `display-l`, the `l` primary button, and the email as a text link.
- It must differ per page: never the identical band on every page.
- Contact has no invitation (it *is* one). Careers uses "Introduce yourself" with the careers email. Legal pages end with a contact line.
