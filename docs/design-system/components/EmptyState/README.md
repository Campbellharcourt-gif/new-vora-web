# EmptyState

One honest sentence and at most one action, where content doesn't exist yet.

**The consumer provides:** the sentence and the action. Use the existing copy where it exists:

- **Work:** "Case studies are being prepared for publication." + "get in touch"
- **Careers:** see CareerRow
- **Admin Enquiries:** "No enquiries yet."
- **Client portal:** "There are no engagements shared with you yet. Your VORA contact will add them here."

**Don't:** illustrations of empty boxes, mascots, or filler content.
