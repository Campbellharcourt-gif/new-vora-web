# SiteFooter

The footer re-composes existing data: the wordmark and partner line, the site links, the contact addresses and social links, then legal, status, sign-in and the Motion toggle.

**The consumer provides:** the partner line and email addresses from settings, the social links, the signed-in state (Sign in / Account) and the current motion preference.

**Rules**

- `color-surface` with a 1 px top line.
- The Motion toggle (Full / Reduced) stores the visitor's choice in a functional cookie, which must be listed on the Cookies page.
- No back-to-top rocket, no newsletter box, no giant cropped wordmark.
- **Mobile:** the groups stack, with hairlines between them.
