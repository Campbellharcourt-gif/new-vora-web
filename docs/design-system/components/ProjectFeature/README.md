# ProjectFeature

One real project per shot: a wide aperture with the title overlapping its lower-left edge, the index, category and summary, and one link.

**The consumer provides:** a published project (`title`, `category`, `summary`, `coverMediaId` with alt text and focal point) and its position (`01 / 02`).

**Use it for:** Home's Chambers station and the top of Work — the sequence Work uses while fewer than four projects are published.

**Rules**

- 21:9 on laptop and desktop, 4:5 on mobile with the title below the frame.
- Only published, real projects. No placeholders in production: with nothing published, the page shows its empty state.
- Clicking morphs the cover into the case-study hero (View Transitions, 700 ms `ease-in-out`).
