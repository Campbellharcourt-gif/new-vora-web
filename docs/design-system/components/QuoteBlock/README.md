# QuoteBlock

A pull quote in Newsreader Italic with a DM Mono attribution — only for a real person's own words.

**The consumer provides:** the quote, the person's name and role, and (for any client quote) the confirmation that it is real, attributable and approved.

**Rules**

- Style `quote`; at most 32 characters per line; hung opening punctuation.
- Testimonials are switched off until each one is confirmed (decision D13). No carousels, at most one per page.
- The example is the founder's line from the previous site, subject to review of the Our Story draft.
