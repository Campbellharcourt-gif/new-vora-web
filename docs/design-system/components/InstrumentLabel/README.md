# InstrumentLabel

Small DM Mono uppercase labels that carry real metadata — section index, chapter name, category, year, status.

**Use it for:** section labels (`02 — SERVICES`), project metadata (`ESPORTS · 2025` once a year is entered), form sections (`01 — ABOUT YOU`), statuses and references.

**The consumer provides:** the text. It is always paired with the thing it describes.

**Rules**

- Style `label` (12 px, 0.14em tracking, uppercase) in `color-text-secondary`; data values use `data`.
- Indices count only sections that exist on that page. Never pad the numbering.
- Never fake coordinates, fake statistics or "system online" theatre.
