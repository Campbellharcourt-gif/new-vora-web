# SectionHeader

A label, a title and an optional lead and link — the start of every section, in the editorial margin-label layout on desktop.

**The consumer provides:** the label (`INDEX — NAME`), the title, an optional lead (at most 52 characters per line) and an optional arrow link.

**Rules:** the label shares the title's left edge, or sits in columns 1–3 with the title at 4–11. Title size follows the page context (display-l on marketing pages, heading-l inside long pages).
