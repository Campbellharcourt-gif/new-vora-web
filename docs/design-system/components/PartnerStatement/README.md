# PartnerStatement

The partnership, stated plainly on a Mist chapter: "Creative by Solara. Digital by VORA.", the partner entry and the three principles.

**The consumer provides:** the partner (name, relationship, description from the `partners` table), the statement (the partner line in settings) and the principle copy (the principle bodies are copy slots).

**Rules**

- Always the Mist roles (`data-theme="mist"`). One italic word at most.
- The partnership is shown in VORA's visual language: no Solara colours, type or imagery.
- Link out to the partner only when a verified URL exists.
